# FrizMine Bedrock Plugin

Плагин экономики для сервера Minecraft Bedrock Edition (работает через прокси Nukkit/Waterfall или на ядре, совместимом с Bukkit API).

## Установка
1. Скачайте файл `.jar` из вкладки **Actions** (артефакты).
2. Положите файл в папку `plugins/` на вашем сервере.
3. Перезагрузите сервер.

## Команды
- `/economy` — проверить баланс.

## Конфигурация
Все настройки находятся в файле `config.yml` в папке плагина.

## Данные предметов
Файл `items_data.json` содержит цены и ID предметов для магазина.
